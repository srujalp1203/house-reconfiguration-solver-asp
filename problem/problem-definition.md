# Problem Definition

The House (Re-)Configuration Problem defines how items owned by persons can be stored in cabinets placed within rooms, subject to structural and ownership constraints.

---

## Entities

- Persons
- Things
- Cabinets
- Rooms

---

## Assignments

- Each thing is assigned to exactly one cabinet
- Each cabinet is placed in exactly one room

---

## Ownership Rules

- A room may contain cabinets belonging to only one person
- Cabinets may store only items owned by that person
